## Description

Check the whole SVG bundle before a buyer does.

**Version 1.0.0 · 61.3 KB ZIP · Updated August 27, 2026**

SVG Bundle Preflight is a private, offline release-QA utility for Etsy and Gumroad sellers who package original Cricut-compatible SVG cut-file bundles.

### How it works

1. Drop in one ZIP or choose SVG files from your computer.
2. Review blockers, bundle warnings, exact duplicates, and case-insensitive filename collisions.
3. Export CSV and self-contained HTML evidence reports.

### It checks for

- malformed XML and documents without an SVG root;
- missing or invalid sizing metadata;
- live text, clipping paths, pattern fills, and gradients;
- linked resources, embedded bitmap images, scripts, and active URL references;
- exact duplicate file bytes; and
- paths that collide on case-insensitive systems.

Your artwork stays in your browser. There is no upload, account, API key, subscription, analytics, telemetry, persistent browser storage, or outbound network request. Input files are never modified.

### Supported limits

- one ZIP up to 50 MB compressed;
- up to 100 MB of expanded SVG content;
- up to 500 SVG files;
- up to 2 MB per SVG and paths up to 240 characters; and
- current desktop browsers.

### Important boundaries

This utility performs static preflight checks. It does not repair files, trace raster artwork, weld paths, validate DXF/EPS/PNG, recurse into nested archives, test physical cuts, automate Design Space, or provide licensing or legal advice. A static pass does not replace representative imports and a real test cut.
