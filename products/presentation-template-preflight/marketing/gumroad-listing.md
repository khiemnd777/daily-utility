## Summary

Audit an editable PowerPoint template locally for broken package links, font portability risks, hidden content, and buyer-ready release evidence.

## Description

Your presentation can look finished and still carry delivery risks that are hard to see: a missing internal package part, a video linked to your computer, an unembedded font, forgotten notes or comments, a hidden slide, an embedded object, a macro project, or author metadata.

Presentation Template Preflight checks one final `.pptx` or `.potx` file entirely inside your browser. It inventories slides, layouts, masters, dimensions, and relationships; maps referenced font families to embedded-font records; and exports CSV plus self-contained HTML evidence for your release record.

### What it checks

- Broken internal OOXML relationship targets
- External local-file, media, data, and web relationships
- Referenced fonts without matching embedded-font records
- Comments, speaker notes, hidden slides, and embedded objects
- VBA macro projects and creator/last-modified metadata
- File name, byte size, SHA-256, scan time, severity totals, and exact package-part evidence

### Private by design

The download runs from `file://` in a current desktop browser. It has no account, upload, analytics, telemetry, remote fetch, or persistent browser storage. Your presentation is not changed.

### Important limits

This is a static OOXML audit, not a PowerPoint renderer or compatibility guarantee. It does not repair files, determine font installation or licensing, certify accessibility, evaluate slide design or animation, execute macros or embedded objects, open legacy `.ppt`, or decrypt protected files. The documented input limit is one 100 MB `.pptx` or `.potx` package.
